# Skills Directory & Installation Sources

A complete reference directory of all 75 agent skills installed in this setup. Includes direct GitHub upstream repositories, skills.sh marketplace links, and one-line installation commands so anyone can easily install and replicate this setup.

## How to Install Any Skill

You can install any of these skills into your local environment (Antigravity, Claude Code, Cursor, Codex) using one of the methods below:

### Method 1: Using the `skills` CLI (Recommended)
```bash
# Install via skills.sh repository
npx skills add <author>/<repo>/<skill-name>
```

### Method 2: Direct Git Clone
```bash
# Clone directly into your global agent skills folder:
git clone --depth 1 <github-url> ~/.config/skills/<skill-name>
```
